publication is authorized. The [specification](docs/fan-app-specification.md)
owns detailed scope; no delivery dates are promised.

| ------------------------------ | ------------------- | ----------------------------------------------------------------------------------------------- |
| Expo foundation                | Implemented         | Neutral iOS/Android starter and local checks                                                    |
| Contributor and agent workflow | Implemented locally | Portable instructions, security checks and work ownership; hosted CI awaits authorized delivery |
| Product decisions              | Partly resolved     | Calculation policy, ESG totals, auth provider and selected design                               |
| Interactive fan prototype      | Planned             | Singapore routes, persistent demo profile, simulation, points, Redemption and History           |

records implementation; update its owning issue and this roadmap when warranted.
