# Planned backend

This directory reserves the conventional location for future Convex functions.
There is no schema, authentication, generated client, or live connection yet.
Do not run Convex setup as part of starting this repository.

Later feature work should test fan/admin workflows through one authenticated
Convex application boundary with controlled time, Maps responses, and location
samples. Real background tracking and arrival need separate physical iOS and
Android checks. None of that behavior is implemented or tested by this starter.
