# Fan and admin experience

The committed app is an Expo development starter. Separate local changes add
Home and navigation tabs, with Travel, Rewards and Impact placeholders. Those UI
changes are outside the documentation commit. The product experiences below are planned.

Fans will use the phone app to compare journey duration and estimated emissions,
complete real journeys checked using location, and spend earned points on fan
submissions, tree dedications, exclusive content and merchandise discounts.
Rewards has Redemption and History tabs.
Accounts start at zero points. A separate demo profile supports labelled
simulation; simulated awards do not enter a real account's balance.

Fans submit questions or proposed activities through one feature: spend 500 points
to submit, then contribute at least 10 points per vote after admin approval. An
admin closes voting and selects up to three total from one ranking, with earlier
approval breaking ties. Optional tags may describe the content without changing
its voting or selection rules. Missing GPS receives up to 50 points, capped at the
expected journey award, only when the app recorded the start and arrival. The existing 2,000-point
journey cap remains; there is no additional daily points cap. Later GPS evidence
can add only the remaining points for that journey, such as 70 after a 50-point
fallback when the supported total is 120.

Admins will use a separate web app to manage rewards, earning rules, reasoned
point adjustments, fan submissions, ESG records and demo examples. They
upload sustainability reports, review the extracted figures and approve them for
the dashboard. A visible badge indicates an assigned role; it does not itself
grant access.

Impact shows personal and community lifetime estimated travel savings beside
separate official team figures. Route savings compare with one person driving
between the same places; the extra-time limit is measured from the fastest route.

Tree participation, vouchers and driver outcomes remain demonstration fulfilment
until arrangements exist. Team-reported ESG activity and personal examples remain
distinct. See the [roadmap](../../ROADMAP.md) and
[feature specification](../features/README.md) for accepted scope and remaining implementation work.

For installation, use the root [README](../../README.md). Report non-sensitive
defects through [Contributing](../../CONTRIBUTING.md); report sensitive security
findings using [SECURITY.md](../../SECURITY.md).
