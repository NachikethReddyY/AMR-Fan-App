# Domain docs

This repo uses a single-context layout: `CONTEXT.md` at the root and ADRs in `docs/adr/`.

Before exploring an area, read the root `CONTEXT.md` and relevant ADRs if they exist. Their absence does not require creating them; the domain-modeling skill creates them when terms or decisions are established.

Use terms defined in `CONTEXT.md` when naming domain concepts. If a proposal conflicts with an ADR, identify the conflict explicitly.
