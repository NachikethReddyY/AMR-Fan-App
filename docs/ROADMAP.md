This is a public-ready summary of intent. The repository remains private until
publication is authorized. The [specification](fan-app-specification.md)
links to the [feature documents](features/README.md) that own detailed scope; no delivery dates are promised.

| Stage                          | State                | Observable outcome                                                                               |
| ------------------------------ | -------------------- | ------------------------------------------------------------------------------------------------ |
| Expo foundation                | Implemented          | Neutral iOS/Android starter and local checks                                                     |
| Contributor and agent workflow | Implemented locally  | Portable instructions, security checks and work ownership; hosted CI awaits authorized delivery  |
| Product decisions              | Core scope confirmed | Feature specifications ready; technical inputs, auth provider and final screen selection remain  |

records implementation; update its owning issue and this roadmap when warranted.
