## Recording each candidate

1. Record source head and uncommitted source hash, backend revision, fixture
   configuration, app bundle/build mode, exact simulator model and OS. Label
   controlled provider auth separately from hosted Supabase.
2. Start on the signed-out app. Capture validation and confirmation. Stop capture
   before entering any password or token. Resume capture only after submission
   has cleared the password field. Document these cuts instead of implying a
   continuous credential-entry recording.
3. Capture correct/incorrect sign-in outcomes, cold restart, provider refresh,
   local/API logout and matching expiry. Compare server counters/state without
   recording credentials. Keep partial remote-logout failure explicit.
4. Record meaningful screenshots and supported native video clips for rows 2–8
   when integrated and authorized. State observed result, filename, duration and
   limits. Carry older proof only for unchanged behavior.
5. Record original text size, orientation and accessibility settings. Change only
   the leased device, restore settings and close owned sessions/services. Keep
   installed app and shared data. Do not turn a simulator observation into a
   physical-device or screen-reader speech claim.
